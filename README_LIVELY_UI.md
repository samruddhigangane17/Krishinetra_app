# KrishiNetra — Lively Stitch UI

This version applies the requested Stitch-style visual direction to the Flutter app while retaining the existing navigation and soil-analysis services.

## Run

```powershell
flutter clean
flutter pub get
flutter analyze
flutter run -d chrome
```

The dashboard now uses a visual agricultural hero, green sidebar, animated hover cards, responsive stat cards, recent scans, AI recommendations, weather, quick actions, and government scheme cards.
